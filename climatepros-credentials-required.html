📋 Service Plan Decisions

One plan selected per service. All plans can be scaled up as volume grows.

Service Plan Selected Key Reason Est. Monthly Cost
Azure Service Bus
 Standard Dead-letter queue (failed jobs after 3 attempts), topics & subscriptions, KEDA autoscaling. First 13M operations/month free — well above our expected volume. ~$10
Azure Cache for Redis
 Standard C1 · 4 GB 2-node HA replication, 99.9% SLA. Essential for Celery chord() fan-in and WebSocket pub/sub. 4 GB is well above our job-state needs. ~$50
Neo4j AuraDB
 Professional · 1 GB Production-ready with daily backups, 7-day retention, and HA replication on Azure. The Knowledge Graph is an enhancement layer — Business Critical HA is not required. ~$65
AI Verifier
 Gemini 2.5 Flash · pay-per-use $0.30/1M input tokens — best pricing for our input-heavy workload (~30K tokens/page). 1M token context window, native PDF/image ingestion, Google Cloud DPA (region-pinned, no prompt logging, not used for training). ~$0.029/bid
Azure Monitor + App Insights
 Analytics Pay-As-You-Go Full KQL queries, distributed tracing across FastAPI + Celery, SLO burn alerts, dead-letter alerts, per-model cost tracking. At 80–500 bids/month our log volume (~1–4 GB/month) stays within the 5 GB/month free tier. ~$0 *
Estimated new-service cost: ~$125/month fixed (Service Bus + Redis + Neo4j) + ~$0.029 per bid (Gemini) + ~$0/month (App Insights within free tier). At 200 bids/month the total is approximately ~$131/month.
Service Bus note: Tier upgrades (Standard → Premium) require creating a new namespace — there is no in-place upgrade path. Provision Standard from day one to avoid migration overhead later.

🔧 Infrastructure Prerequisites

These are setup items required before go-live that are not Key Vault secrets.

# Item What Is Needed Who Action
1
Zeus network path
Azure Container Apps → Mac Studio "Tundra" (on-prem)
 A routable network path from Azure Container Apps to the on-prem Mac Studio must be established — either via a VPN gateway or a secured public TLS endpoint with API key authentication. Must be verified end-to-end in staging before production go-live. Client + Techjays
2
Azure Container Registry (ACR)
Docker image storage for FastAPI + Celery worker containers
 Provision an ACR instance (e.g., climatepros.azurecr.io). Container Apps pull images at runtime via managed identity — no runtime secrets needed. CI/CD pipeline push credentials are configured separately in the deployment pipeline, not in Key Vault. Techjays
3
FieldJetX Ingest Endpoint
REST API for pushing extracted bid data back into FieldJetX
 FieldJetX must expose an internal REST endpoint that accepts the structured bid extraction result (equipment list, quantities, line items). The endpoint URL and a service-to-service auth token must be provided — these become FJX_INGEST_URL and FJX_SERVICE_TOKEN in Key Vault (Credential #7 above). Client (FieldJetX team)
4
Azure Container Apps Environment
Workload profile, KEDA scaler, VNet integration
 Provision the Container Apps environment with VNet integration (existing FJX VNet), KEDA scaler configured against the Service Bus queue depth, minimum 0 replicas for Celery workers, and managed identity enabled for Key Vault access and ACR pulls. Techjays
