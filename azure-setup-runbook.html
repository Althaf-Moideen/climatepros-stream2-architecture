What Each Service Does — Plain English
No jargon — what each box actually means for ClimatePros
🚀

Azure Container Apps — FastAPI

cp-ENV-api · External Ingress · 0.5 vCPU / 1 GiB

The web API layer. Receives HTTP requests — bid uploads, estimation requests, job status checks. Stores files to Blob, pushes tasks to Service Bus, returns results. Scales automatically with traffic.

⚙️

Azure Container Apps — Celery Worker

cp-ENV-worker · No Ingress · 1 vCPU / 2 GiB · KEDA

The background processing engine. Picks up tasks from Service Bus, runs AI estimation logic, reads/writes to PostgreSQL, stores reports to Blob. No public access. Scales on queue depth via KEDA.

🌐

Virtual Network (VNet)

cp-ENV-vnet · 10.x.0.0/16

Azure's private network boundary. Traffic between Container Apps and data services never touches the public internet. Each environment has its own completely separate VNet.

🔒

Private Endpoints

data-subnet · Redis · Service Bus · Blob

A private IP inside your VNet for each PaaS service. The service rejects all public traffic. Your app calls the private IP — never the public internet address.

🔍

Private DNS Zones (× 5)

postgres · redis · servicebus · blob · azurecr

Azure's internal phone book. Intercepts DNS lookups and returns the private VNet IP instead of the public one. Without DNS zones, private endpoints don't work even if they exist.

🐘

PostgreSQL Flexible Server

cp-ENV-postgres · v16 · VNet-delegated · AAD Auth

The main relational database. Stores jobs, bids, customers, estimation results. No public endpoint. Apps authenticate with Azure AD tokens — no passwords in code.

🔴

Azure Cache for Redis

cp-ENV-redis · TLS port 6380 · noeviction

The Celery message broker. FastAPI hands off tasks to Celery workers through here. noeviction means tasks are never silently dropped. Connection stored as encrypted Container App secret.

📨

Azure Service Bus

cp-ENV-sb · task-queue · maxDelivery 10

The durable task queue. If a worker crashes mid-task, Service Bus re-delivers automatically (up to 10 retries). Failed tasks go to dead-letter queue. Drives KEDA worker auto-scaling.

🗄️

Azure Blob Storage

cp-ENV-sa... · documents + exports · LRS/ZRS

The file store. Uploaded bid documents in documents; finished estimation reports in exports. All access requires Azure AD identity — no public URLs, no shared keys.

📦

Azure Container Registry (ACR)

cpXXXXacr · Standard · Shared across all envs

The Docker image store. CI/CD pushes FastAPI and Celery images here. Images tagged ENV-GitSHA — every deployment is traceable; rollback = redeploy an older tag.

🔑

Managed Identity (System-Assigned)

Attached to: FastAPI app · Celery worker

An Azure AD identity auto-attached to each Container App. No passwords in code. Each app presents this identity to authenticate with PostgreSQL, Service Bus, and Blob. Azure rotates tokens automatically.

🔄

CI/CD Pipeline

cp-ENV-cicd-sp · GitHub Actions / Azure DevOps

The automated deploy pipeline. On every push to main: builds Docker images → pushes to ACR with commit SHA tag → tells Container Apps to use the new image.

🔐
